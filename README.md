# EXAMBANK - ระบบคลังข้อสอบและการสอบออนไลน์

## โปรเจกต์นี้คืออะไร

EXAMBANK เป็นเว็บแอปพลิเคชันสำหรับจัดการคลังข้อสอบและทำแบบทดสอบออนไลน์ พัฒนาขึ้นเพื่อให้ผู้เรียนสามารถเลือกวิชา ทำข้อสอบแบบจับเวลา และติดตามผลการเรียนของตนเองได้ในที่เดียว ขณะเดียวกันผู้สอนหรือผู้ดูแลระบบสามารถสร้างและดูแลหมวดวิชา ข้อสอบ และบัญชีผู้ใช้งานได้

ระบบมีการเชื่อมต่อกับ Supabase เพื่อจัดเก็บข้อมูลและจัดการการเข้าสู่ระบบ รวมถึงมีฟังก์ชันช่วยสร้างข้อสอบด้วย AI จากเอกสาร PDF หรือ TXT เพื่อช่วยลดเวลาในการเตรียมข้อสอบ

## ทำเพื่ออะไร

โปรเจกต์นี้ทำขึ้นเพื่อ:

- เปลี่ยนการเตรียมข้อสอบและการทำข้อสอบจากเอกสารหรือกระดาษให้เป็นระบบออนไลน์
- รวมคลังข้อสอบของแต่ละวิชาไว้ในที่เดียว และนำกลับมาใช้งานได้ง่าย
- ช่วยให้ผู้เรียนฝึกทำข้อสอบได้ด้วยตนเอง พร้อมตัวจับเวลาและการสุ่มข้อสอบ
- ช่วยให้ผู้เรียนเห็นคะแนน สถิติ จุดที่ควรปรับปรุง และข้อที่เคยตอบผิด
- ลดภาระผู้สอนในการสร้างข้อสอบจำนวนมากด้วยการนำเข้าไฟล์หรือใช้ AI ช่วยสร้าง

## หน้าที่หลักของระบบ

### 1. ส่วนของผู้เรียน (Student)

- เข้าสู่ระบบและแก้ไขข้อมูลโปรไฟล์
- ดูหมวดวิชาและจำนวนข้อสอบที่เปิดใช้งาน
- เลือกจำนวนข้อและเวลาที่ต้องการสอบ
- ทำข้อสอบแบบจับเวลา พร้อมการสุ่มลำดับข้อสอบและตัวเลือกตามการตั้งค่า
- ดูคะแนนและผลการสอบ
- ดูสถิติการทำข้อสอบผ่านหน้า Analytics
- เปิดคลังข้อผิดพลาดเพื่อทบทวนข้อที่เคยตอบผิด พร้อมเฉลยและคำอธิบาย

### 2. ส่วนของผู้สร้างข้อสอบ (Creator)

- สร้างและจัดการหมวดวิชาที่ตนเองรับผิดชอบ
- เพิ่ม แก้ไข ลบ และเปิดหรือปิดใช้งานข้อสอบ
- เพิ่มรูปภาพในโจทย์หรือคำอธิบายเฉลย
- นำเข้าข้อสอบหลายข้อพร้อมกัน
- ใช้ AI สร้างข้อสอบจากเอกสาร PDF หรือ TXT โดยกำหนดจำนวนข้อ ระดับความยาก ภาษา และการกระจายเนื้อหาได้

### 3. ส่วนของผู้ดูแลระบบ (Admin)

- จัดการหมวดวิชาและข้อสอบทั้งหมดในระบบ
- จัดการผู้ใช้งาน
- กำหนดบทบาทของผู้ใช้งาน เช่น `student`, `creator` และ `admin`
- ควบคุมสิทธิ์การเข้าถึงส่วนจัดการหลังบ้าน

## การทำงานโดยสรุป

```text
ผู้ดูแลหรือผู้สร้างข้อสอบเตรียมหมวดวิชาและข้อสอบ
                         ↓
ผู้เรียนเข้าสู่ระบบและเลือกหมวดวิชา
                         ↓
เลือกจำนวนข้อและเวลาสอบ
                         ↓
ระบบเลือกและสุ่มข้อสอบที่เปิดใช้งาน
                         ↓
ผู้เรียนทำข้อสอบและส่งคำตอบ
                         ↓
ระบบตรวจคะแนน บันทึกประวัติ และแสดงผล
```

## เทคโนโลยีที่ใช้

- **Frontend:** React 19
- **Build tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Backend และฐานข้อมูล:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth
- **AI:** Google Gemini API สำหรับช่วยสร้างข้อสอบจากเอกสาร
- **อ่านไฟล์ PDF:** PDF.js
- **Deployment:** Vercel

## วิธีติดตั้งและรันในเครื่อง

### 1. Clone โปรเจกต์

```bash
git clone https://github.com/pornprompoh/Exam_website.git
cd Exam_website/exam-website
```

### 2. ติดตั้ง dependencies

```bash
npm install
```

### 3. ตั้งค่า environment variables

สร้างไฟล์ `.env` หรือ `.env.local` ในโฟลเดอร์ `exam-website/`:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_GEMINI_API_KEY=your-gemini-api-key
```

`VITE_GEMINI_API_KEY` จำเป็นเฉพาะเมื่อจะใช้ฟังก์ชันสร้างข้อสอบด้วย AI

### 4. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา

```bash
npm run dev
```

จากนั้นเปิด `http://localhost:5173`

## คำสั่งที่ใช้บ่อย

```bash
npm run dev      # รันโหมดพัฒนา
npm run build    # build สำหรับ production
npm run preview  # preview ผลลัพธ์หลัง build
npm run lint     # ตรวจสอบรูปแบบและปัญหาในโค้ด
```

## การ Deploy

โปรเจกต์รองรับการ deploy บน Vercel โดยตั้งค่าหลักดังนี้:

- **Root Directory:** `exam-website`
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- เพิ่มค่า environment variables เดียวกับไฟล์ `.env` ในหน้า Project Settings ของ Vercel

ไฟล์ `vercel.json` ใช้ช่วยจัดการ routing ของ React SPA เพื่อให้การเปิด URL หรือรีเฟรชหน้าโดยตรงทำงานได้ถูกต้อง
