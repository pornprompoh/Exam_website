# แผนการพัฒนาโปรเจค (Development Workflow)

เราจะทำงานเรียงตามลำดับนี้ เพื่อให้แต่ละส่วนเชื่อมต่อกันได้อย่างสมบูรณ์ครับ:

---

# Phase 1: Planning & Design

**ออกแบบบนกระดาษหรือเครื่องมือก่อนเขียนโค้ด**

## สิ่งที่ต้องทำ

### ออกแบบหน้าจอ (UI/UX)
- วาดหน้าตาเว็บคร่าวๆ (Wireframe) ว่าหน้าแอดมิน (เพิ่มข้อสอบ) และหน้าผู้ใช้ (ทำแบบทดสอบ) หน้าตาเป็นอย่างไร ปุ่มอยู่ตรงไหน

### ออกแบบฐานข้อมูล (Database Schema)
- กำหนดฟิลด์ในตาราง `questions` และ `exam_history` ให้ชัดเจนว่าจะเก็บข้อมูลอะไรบ้าง

---

# Phase 2: Project Setup & Configuration

**เตรียมโครงสร้างโปรเจคและเชื่อมต่อ API**

## สิ่งที่ต้องทำ

- สร้างโปรเจค React ด้วย Vite
- สร้างโปรเจคใน Supabase (สร้างตารางตามที่ออกแบบไว้ใน Phase 1)
- สร้างโปรเจคใน Firebase (เปิดใช้ Storage และตั้งค่า Rules ให้สามารถอัปโหลดไฟล์ได้)
- ติดตั้ง Library ที่จำเป็น (`@supabase/supabase-js`, `firebase`) และตั้งค่าไฟล์ `.env` สำหรับเก็บ API Keys

---

# Phase 3: Admin & Data Management

**ทำระบบฝั่งหลังบ้านให้ใช้งานได้ก่อน**

## สิ่งที่ต้องทำ

- สร้างหน้าฟอร์มสำหรับเพิ่มข้อสอบ
- เขียนฟังก์ชันอัปโหลดรูปภาพไปยัง Firebase Storage และรับ URL กลับมา
- เขียนฟังก์ชันนำข้อมูลข้อสอบ (รวม URL รูป) ไปบันทึกลงตารางใน Supabase
- ทำระบบแก้ไขและลบข้อสอบ (อย่าลืมฟังก์ชันลบรูปใน Firebase ก่อนลบข้อมูลใน Supabase)

---

# Phase 4: User Experience (Exam System)

**ดึงข้อมูลมาแสดงผลและทำระบบการสอบ**

## สิ่งที่ต้องทำ

- สร้างหน้าแสดงรายการข้อสอบให้ผู้ใช้เลือก
- สร้างหน้าทำแบบทดสอบ (ดึงโจทย์ ช้อยส์ และรูปภาพจาก `image_url` มาแสดง)
- เขียนลอจิก (Logic) ใน React เพื่อเก็บคะแนน ตรวจคำตอบที่เลือก และการเปลี่ยนข้อ
- สร้างหน้าสรุปผลคะแนน พร้อมแสดงเฉลยและคำอธิบายโดยละเอียด

---

# Phase 5: Testing & Deployment

**เตรียมพร้อมก่อนปล่อยของจริง**

## สิ่งที่ต้องทำ

- ทดสอบเพิ่ม/ทำ/ลบ ข้อสอบว่าทำงานถูกต้องไหม (ลองใช้รูปไฟล์ใหญ่ๆ เพื่อดูการตอบสนอง)
- นำโค้ดไปฝากไว้บน GitHub
- นำเว็บขึ้นโฮสต์จริง (Deploy) ฟรีๆ ผ่าน Vercel หรือ Netlify เพื่อให้เราสามารถเปิดใช้งานผ่านมือถือหรือส่งลิงก์ให้คนอื่นได้
